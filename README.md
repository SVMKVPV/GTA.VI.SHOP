# Sunset District — GTA.VI.SHOP storefront preview

Original neon-coastal visual direction inspired by tropical sunset nightlife. This project is **not affiliated with Rockstar Games or Grand Theft Auto** and includes no official GTA artwork, logos, or assets.

## Preview
Open `index.html` in a browser or deploy the static files to Netlify. The storefront has responsive cards, filters, search, and a local demo cart.

## Important
- All nine product listings, prices, icons, and descriptions are **illustrative**, not real sourced inventory.
- No customer payments, supplier orders, tracking, or stock sync are enabled.
- Verify actual suppliers on AliExpress, Alibaba, CJdropshipping, or through DSers, including rights to imagery, Australian shipping, returns, product compliance, and actual landed costs.
- Before commercial launch, implement verified product imports, Stripe Checkout or another approved payment gateway, tax/shipping logic, inventory sync, order fulfilment, privacy/terms/refunds, contact details, and end-to-end testing.
- The repository was empty aside from its README when this branch was created. All source changes are isolated on a feature branch for review.

## Suggested sourcing workflow
1. Supplier product URL → review queue with supplier, shipping, variants and images.
2. Supplier vetting and price/fulfilment approval before publishing.
3. Calculate landed cost (product + shipping + GST/duties where applicable + fees + returns allowance) and margin.
4. Publish only verified SKUs; fulfil orders through an authorised connection such as DSers or direct supplier integration.
